# ArriveKR · 탑승부터 원주 정착까지

> 동북권 오픈소스 아이디어톤 · 주제: 지역 주민 맞춤형 공공지원사업 추천 서비스
> 팀 안병잘부 (상지대학교)

**실제 같은 탑승권으로 시작해 → 체류자격(비자)을 고르고 → 내 나라에서 인천까지 비행하며 입국 준비를 마친 뒤
→ 원주에 내려 "외국인주민 맞춤 공공지원"을 추천받는 서비스**입니다. (원주 → 강원 → 인근 시군 → 전국 순서)
한국어 · English · Tiếng Việt · Bahasa Indonesia · ខ្មែរ · नेपाली

## 데이터 (확인일 2026-11-08 · 원주 2026-11-09)

  - 지도 핀 중 시청 외에는 **대략 위치**(방문 전 전화 확인). 기간·대상은 바뀔 수 있어 카드마다 연락처·출처를 함께 표시

- `src/data/countries.js` — 송출국 18개: 송출기관·누리집·응시료·추가 서류·나라별 위험, **확인 수준**(공지 원문 / 정리 글 / 송출기관만)

  - 나머지는 송출기관 목록만 확인 → 화면에 "공지 확인 필요"로 표시
- `src/data/route.js` — 구간·항목·난기류(6개 언어). 근거: 한국산업인력공단 고용허가제 안내, 외국인고용법 제7·9·10·11조, 출입국관리법 제31조

- E-9 송출국이 아닌 나라는 일반 취업 비자(E-7 등) 기본 흐름만 보여 줍니다.
- 나라 경계: Natural Earth(world-atlas) · 지구 사진: NASA Blue Marble(three-globe 예제 이미지)

## 실행 · 배포

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
```

Vercel: 저장소 Import → Deploy. `api/tutor.js` 는 Vercel 함수로 자동 배포됩니다.

| 환경변수 | 용도 |
|---|---|
| `GEMINI_API_KEY` | 한국어 도우미 "AI에게 묻기" (없으면 연습 문제만 동작) |
| `GEMINI_MODEL` | 선택. 기본 `gemini-2.5-flash` |

## 로그인에 대해 (데모)

서버 없이 **이 브라우저 안에만** 계정을 만듭니다. 비밀번호는 PBKDF2(SHA-256, 120,000회)+소금으로 바꿔 저장하지만,
다른 기기와 공유되지 않습니다. 실제 운영에서는 `src/lib/auth.js` 를 Supabase Auth 등 서버 로그인으로 바꾸세요.

## 다른 나라·체류자격으로 넓히기

`countries.js` 에 나라를, `route.js` 에 체류자격(E-8 계절근로, H-2 방문취업 등)별 구간을 더하면 됩니다.
