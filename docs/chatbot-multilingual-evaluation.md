# 다국어 평가 및 출처 링크 변경 결과 (2026-11-03)

## 평가 범위

실제 Gemini 키가 없어 모의 응답 기반으로 평가했습니다. 실제 분류 정확도·다국어 생성 품질·번역의 자연스러움을 평가한 결과가 아닙니다.

6개 지원 언어: 한국어, 영어, 베트남어, 인도네시아어, 크메르어, 네팔어.
각 언어의 질문 입력은 tests/chat-multilingual.cjs에 있습니다.

언어별 4개 테스트, 총 24개 추가:
- 범위 밖 → 정상 → 다시 범위 밖 3턴 흐름과 요청 격리, 생성 프롬프트의 언어 지정
- 모호한 질문의 해당 언어 안내
- E-9을 언급한 무관 질문의 해당 언어 거절
- 근거 부족의 해당 언어 안내

기존 13개 + 다국어 24개 + 출처 링크 3개 = 전체 40개 통과.
실행: node --test tests/chat-policy.test.cjs

미지원 잔존 파일 my/si/th/uz도 검사기에서 경고됩니다. 지원 언어 수와 구분해야 합니다.
새 거절·근거 부족 문구와 출처 섹션 제목은 6개 언어 모두 존재합니다.
원어민 검수, 실제 생성문의 수치·기한 보존, 모델의 범위 판별 검증은 미완료입니다.

## 출처 링크 표시

답변 → 기존 근거·확인일 → 기존 안내사항 → 공식 출처 링크 순서입니다.
추천 질문 8개를 포함한 기존 KB 항목 및 서버 문서에 출처 목록을 연결했습니다.
assets/chat-sources.js를 브라우저와 서버가 공유합니다. AI가 제시한 임의 URL은 사용하지 않습니다.
서버 응답 sources[].links로 등록 URL을 전달하고 브라우저에서도 등록 목록과 일치하는 URL만 허용합니다.
새 창으로 열고 noopener/noreferrer를 적용하며, 텍스트로 표시해 HTML을 실행하지 않습니다.
법령명·조문명은 원문 대조를 위해 한국어로 표시하고 섹션 제목은 사용자 언어로 표시합니다.
제도 내용의 최신성 검토나 확인일 갱신을 수행한 것은 아닙니다.
기관 홈페이지 링크는 공식 안내 진입점이며 세부 절차 전체를 직접 입증하는 링크는 아닙니다.

## 추가 배포 파일

기존 변경 파일 api/ask.js, api/_chat-policy.js, api/_gemini.js, assets/app.js에 더해:
- assets/chat-sources.js (신규 공유 출처 목록)
- assets/style.css (출처 링크 스타일)
- ask.html (출처 목록 스크립트 로드)

테스트 파일은 서비스 실행에 필요하지 않습니다. 배포 시 정적 파일/PWA 캐시 갱신을 담당자와 함께 진행해야 합니다.
로컬 http://localhost:8000/ask.html에서 추천 질문 답변 링크의 표시를 확인했습니다.
